# Qatar Job Android App

This Android app is built around the user's Qatar Job website:
https://siddik009.github.io/qatar-job/

- App name: Qatar Job
- Application ID: com.qatarjob.app
- App icon included: `app/src/main/res/drawable/qatar_job_icon.xml`
- GitHub Actions workflow: `.github/workflows/build.yml`
- APK artifact name: `Qatar-Job-APK`

The app opens the live Qatar Job website in an Android WebView, keeps JavaScript/local storage enabled for the site's interactive features, and hands phone, email, and WhatsApp links to Android when appropriate.


## App icon
The launcher icon uses the Qatar Job icon supplied by the project owner (`ic_launcher.png`).
